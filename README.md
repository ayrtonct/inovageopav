# InovaGeoPav — landing page

Página estática do grupo de pesquisa InovaGeoPav (Uema), com acesso ao Thermoasfalto, ao LAPS e ao Lattes da coordenação.
É o destino do QR Code e da tag NFC da folha A4.

- `index.html`: a página inteira (HTML + CSS, sem build)
- `favicon.svg`: símbolo do grupo (conceito D, provisório até a escolha da logo)

Os trechos entre colchetes com fundo amarelo (`[...]`) são campos a preencher.

Publicação: projeto importado no Vercel, sem framework e sem comando de build. Cada push na `main` publica.
